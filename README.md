# Klar — немецкая грамматика A1–B1

План и актуальные отметки выполнения: [PRIORITIES.md](PRIORITIES.md).

Рабочий первый этап на React, TypeScript, Vite, Tailwind CSS 4 и Lucide.

## Локальная разработка и самостоятельная публикация

По просьбе пользователя дальнейшие изменения выполняются только локально. Команд автоматического deploy/publish нет. Для самостоятельной публикации выполните `npm run build` и загрузите содержимое `dist/` на статический HTTPS-хостинг. `.openai/hosting.json` сохраняет идентификатор старого размещения и сам по себе ничего не публикует. Отключение уже опубликованного сайта — отдельное действие в управлении Sites; локальная пересборка его не отключает.

## Установка на телефон

После самостоятельной публикации HTTPS-версия поддерживает установку как PWA. Android: Chrome → меню → «Установить приложение». iPhone: Safari → «Поделиться» → «На экран Домой» → «Открывать как веб-приложение». Это установка с сайта, без Google Play и App Store.

После успешного кэширования и уведомления «Klar готов к работе офлайн» доступны грамматика, словарь и тренажёры. Первое открытие требует сети. Синтез речи зависит от немецкого голоса устройства; запись Hallo включена в офлайн-кэш. Прогресс локален для браузера/установленного приложения и не переносится автоматически с localhost на опубликованный домен.

PWA работает в production-сборке (`npm run build`, затем `npm run preview`); в Vite dev service worker отключён. Обновления применяются по кнопке, чтобы не прерывать упражнение.

## Запуск

```sh
npm install
npm run dev
```

Сборка: `npm run build`. Проверки данных: `npm test`. Предпросмотр сборки: `npm run preview`.

## Возможности

- Адаптивная главная, навигация, светлая и тёмная темы. Уровни A1/A2/B1 отключены до появления отдельных программ.
- Отдельный справочник общих правил: 9 тем — окончания Präsens с конструктором и переводом, падежи и артикли, местоимения, порядок слов, построение вопросов, отрицание nicht/kein, предлоги, склонение прилагательных и прошедшее время.
- Конструктор вопроса: утверждение → вопрос → русский перевод. Пять типов конструкций, вопросы да/нет и с вопросительным словом. Таблицы W-слов, wer/wen/wem/wessen, вежливых и косвенных вопросов, коротких ответов ja/nein/doch.
- 2000 уникальных слов и устойчивых выражений с русским переводом, артиклями существительных и приблизительным чтением кириллицей. Это редакционная тематическая подборка, не официальный частотный список.
- Словарь: скрытый перевод, немецкая озвучка, поиск, темы, режимы карточек/списка, списки «Изучаю» / «Знаю» / «Новые».
- Слова автоматически перемешиваются при каждом открытии словаря. Перемешанный порядок сохраняется при ответах и применяется ко всем спискам и темам.
- Озвучка ждёт загрузки именно немецкого голоса, предлагает выбор голоса и скорости. Hallo использует локальную запись носителя (Jeuwre, CC BY-SA 4.0; сведения в `public/audio/de/ATTRIBUTION.md`). Остальные слова и предложения используют голос устройства; качество зависит от доступных голосов.
- Тренажёр артиклей и множественного числа: случайные подходы по 10 слов, ввод Plural, кнопки умлаутов, полная пара форм и объяснение после ответа.
- Сборка предложений: 1588 уникальных упражнений с лицами, временем и разной лексикой. Темы: повседневная речь, вопросы да/нет, вопросительные слова, Perfekt, модальные конструкции, порядок слов и падежи. Подходы по 5/10/20/50 заданий; поиск и фильтр не закреплённых. Новые подходы в первую очередь выбирают ещё не освоенные предложения.
- «Моя фраза»: ввод русского предложения → немецкий вариант, озвучка, копирование, собственное упражнение на сборку, последние 20 фраз в localStorage. Совпадения с библиотекой и пример «Я вчера играл в футбол с друзьями» работают офлайн. Остальной текст отправляется в MyMemory только после нажатия кнопки. Запросы до 500 байт UTF-8, анонимный лимит сервиса — 5000 символов в день (https://mymemory.translated.net/doc/usagelimits.php). Ключ не требуется, добавления в публичную память переводов не выполняются. Автоматический перевод может быть неточным. Ошибки сети, лимитов и таймауты показаны пользователю.
- Регистрация PWA использует стандартный `navigator.serviceWorker`, без импорта `virtual:pwa-register/react`; локальный Vite dev не зависит от виртуального модуля. Обновления production-приложения по-прежнему применяются вручную.
- План на 10 минут: одно правило (≈2 минуты), 5 слов (≈4 минуты), два артикля и одно предложение (≈4 минуты). Набор стабилен в пределах даты по Europe/Berlin. План не запускает фоновое расписание и не требует таймера. Выполненные шаги и результаты сохраняются; ошибки не засчитываются в освоенные формы, но завершённый подход учитывается в плане.
- Повторение текущей выборки (до 20 слов): 4 варианта перевода, итог, перенос ошибок в «Изучаю». Правильные ответы переходят в «Знаю». Статусы слов сохраняются отдельно от спряжений и темы в localStorage.
- 71 глагол Präsens: sein, haben, werden, все 6 модальных, слабые и сильные.
- Поиск, фильтрация, шесть форм с объяснениями на русском и цветным выделением.
- Примеры с браузерной озвучкой (требуется доступный немецкий голос).
- Тренировка: случайные подходы на 12/24/36 заданий. Для каждого глагола 24 разных задания: форма, пропуск, вопрос, исправление ошибки; длинный подход повторяет часть заданий. Освоение по-прежнему учитывает шесть уникальных личных форм.
- Прогресс учитывает уникальные правильно введённые формы. Тема и прогресс сохраняются в localStorage; без аккаунтов и синхронизации.

## Архитектура

`src/data/verbs.ts` — глаголы и правила выделения; `src/data/rules.ts` — таблицы общих правил; `src/data/vocabulary.ts` — 2000 карточек и состояния; `src/data/vocabularyPractice.ts` — очереди практики; `src/components/Rules.tsx` — справочник; `src/components/Vocabulary.tsx` — словарь; `src/components/Conjugation.tsx` — спряжения; `src/components/Practice.tsx` — тренировка спряжений; `src/hooks/useStoredState.ts` — устойчивое хранение; `src/hooks/useSpeech.ts` — озвучка; `src/App.tsx` — навигация и обзор; `src/styles.css` — тема и адаптивная сетка.

Озвучка использует Web Speech API и немецкий голос устройства; при недоступности выводится сообщение. Кириллическая подсказка не является IPA, не передаёт все звуки и не заменяет аудио. Прогресс не синхронизируется между устройствами.

Видеокурс A0–B2 доступен на странице курса; C1/C2 пока без программы. Уровни видеокурса, словаря и глаголов — независимые фильтры. Справочник включает общие схемы, а тренажёр спряжений охватывает Präsens.

## Учебный центр — 29 октября 2026

Добавлены восемь авторских мини-уроков Klar: знакомство, кафе, время, пекарня, дорога, запись на приём, вчерашний день и объяснение причины. Шесть уроков A1 и два A2 — начало последовательной программы, не полный курс этих уровней. Каждый связывает диалог, выражения, правило, свои письменные ответы и слова урока в повторении. Материалы новых уроков двуязычные RU/UK.

Четыре навыка слова: узнавание, письменное вспоминание русского перевода, немецкое написание с учётом заглавных букв и диктант на слух. Значения базового словаря пока русские. Для 81 проверенного существительного показана пара единственного/множественного числа. Старые статусы «Знаю/Изучаю» сохранены отдельно.

Интервалы: 10 минут, 1/3/7/14/30/60 дней; ошибка возвращает к короткому интервалу. Раннее повторение не повышает ступень и не переносит срок. Это прозрачное расписание, без обещания предсказать забывание. Новые ошибки из словаря, глаголов, артиклей, предложений и мини-уроков собираются в общем разделе. Для закрепления ошибки нужны верные повторения после паузы; старые попытки до обновления не восстанавливаются.

Аудирование использует немецкий голос устройства с обычной и замедленной скоростью. Озвучка может зависеть от сети и установленных голосов. Если голоса нет, в мини-уроке можно прочитать текст; это не засчитывается как проверка слуха. Запись микрофона — локальный MediaRecorder, только после нажатия и разрешения пользователя, до 60 секунд; никуда не отправляется и не сохраняется после выхода из страницы. Автоматической оценки произношения нет.

План предлагает просроченные повторения, ошибки и незавершённый урок. Свободный письменный режим добавлен к сборке предложений; принимаются подготовленные варианты, в том числе проверенные варианты с временем в начале. Это не проверка произвольного немецкого текста с ИИ. Основные формы прошлого добавлены всем 71 глаголу; практические примеры стоимости используют товары.

Учебный опыт XP даётся за разные закреплённые результаты и завершённые уроки, а не за нажатия и многократный повтор одного ответа. Это игровой уровень, не CEFR. Награды серии продолжаются после 30: 40/50/60 дней и далее каждые 10.

Навигация на ПК сокращена, тренажёры объединены в сворачиваемую группу. На телефоне — пять нижних кнопок и меню «Ещё». Все списки выбора заменены доступными комбобоксами с клавиатурой и оформленным меню. Добавлено введение в артикли/множественное число и выровнены значки примечаний.

Новые данные: `klar:learning:v1`, опыт `klar:xp:v1`. Учебный центр имеет экспорт/импорт своей копии с проверкой, предварительным просмотром и отменой последнего импорта. Старые ключи словаря, тренажёров и видеокурса не изменены. Никаких новых зависимостей или платных API не требуется.

Достижения объединены в шесть развивающихся категорий. Одна карточка повышает ранг: бронза → серебро → золото → алмаз. Для серии: 3/10/30/60 дней, затем дальнейшие ступени на той же карточке. Полученный ранг и прежние награды сохраняются после перерыва.

## Недельный отчёт и объяснения ошибок

«Мой прогресс» и вкладка «Моя неделя» учебного центра показывают последние семь календарных дней по времени Берлина: активные дни, проверенные ответы, точность, разные слова с верными ответами, завершённые мини-уроки, переходы навыков на третью ступень и закреплённые трудности. Общий список «Знаю» показан отдельно от проверенных навыков. Активные слабые места и просроченные повторения ведут прямо к практике.

Дневной журнал добавлен как необязательное поле journal в klar:learning:v1: прежние сохранения и копии принимаются. Он собирается с новых попыток/шагов мини-уроков, хранит агрегаты за 90 дней, не восстанавливает старые ответы по догадке. Дни активности из прежних тренажёров/видеокурса сохранены; видео и отметки словаря не становятся проверенными ответами. Сравнение с предыдущей неделей доступно после полного периода наблюдения.

Подсказки после ошибок добавлены в семь мест: предложения, глаголы, существительные, практику словаря, интервальное повторение, мини-уроки и повтор ошибок. Они сравнивают ответ с подготовленными образцами и разбирают порядок слов, вопросы, глагольную рамку, окончания, род, множественное число, артикль, регистр и умлауты. Кнопка «Открыть правило» выбирает соответствующую тему справочника. Это локальные подсказки, не свободная проверка текста с ИИ; для неоднозначных ответов сохранена оговорка о других верных формулировках. Новые разделы поддерживают RU/UK и обе темы.
